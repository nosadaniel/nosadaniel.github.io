#### 9. Efficient Domain Adaptation for LLMs – Phishing Email Analysis
- **Company:** cyberGEIGER GmbH
- **Period:** 2025 - 2026
- **Tech Stack:** Python, PEFT/LoRA (via Unsloth), Supervised Fine-Tuning, LLM Evaluation
- **Description:** Domain-adapted a foundation model (Llama 3.1 8B) via supervised fine-tuning and LoRA adapters so it can reason about phishing threats, not just classify them. Built an instruction-style data synthesis pipeline and a separate evaluation pipeline; collaborated with Luong NGUYEN.
- **Verified Technical Details** *(pulled directly from the published HF model/dataset cards, 2026-09-06)*:
  - **Base model:** `unsloth/llama-3.1-8b-bnb-4bit` (quantized Llama 3.1 8B)
  - **Fine-tuning:** LoRA via Unsloth, fp16 mixed precision, 3 epochs, learning rate 2e-4, batch size 32
  - **Dataset:** 200 balanced samples derived from the CEAS-08 phishing dataset, synthesized into instruction/response pairs using `gpt-oss-120b`, 16.4MB JSONL, MIT licensed
  - **Results:** Accuracy 93.4% (vs. 91.4% baseline), Precision 97.4%, Recall 89.1%, F1 93.1%
- **Links:**
  - Live Demo: huggingface.co/spaces/nosadaniel/fined-model *(note: Space sleeps when inactive — will need a "may take a moment to wake up" note on the portfolio, or a static screenshot fallback)*
  - LoRA Adapter: huggingface.co/nosadaniel/llama3-1-8b-tuned
  - Instruction Dataset: huggingface.co/datasets/nosadaniel/phishing-email-training-dataset
  - Training Notebook: colab.research.google.com/drive/1hjLVIx0QZ57dNkAaLahPSwoYZNQkpVXz
- **Role:** Full research and development
