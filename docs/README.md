# Vibe Product Development Guide

A comprehensive set of prompts and guidelines to transform your idea into a successful product and business. This repository provides a structured approach to product development, from initial concept to market launch.

## Project Structure

1. **Ideation & Brainstorming** (`prompts/step-1-brainstorm.md`)
   - Structured process for idea exploration and refinement
   - Technical context gathering
   - Critical evaluation
   - Improvement suggestions

2. **Product Planning**
   - Product Requirements Document (`prompts/step-2.0-prd.md`)
   - System Architecture (`prompts/step-2.1-architecture.md`)
   - UI/UX Design (`prompts/step-2.2-ui-ux.md`)

3. **Business Development**
   - Lean Startup Canvas (`prompts/step-3.0-generate-the-lean-startup-canvas.md`)
   - Go-to-Market Strategy (`prompts/step-3.1-generate-gtm-strategy.md`)
   - Pitch Deck Creation (`prompts/step-3.2-pitch-deck.md`)

4. **Project Management**
   - Task Breakdown (`prompts/step-4-tasks.md`)
   - Todo List (`prompts/step-5-todo-list.md`)
   - Project Rules (`prompts/step-6-generate-rules.md`)
   - Process Initialization (`prompts/step-7-start-the-process.md`)

## How to Use

1. Start with the brainstorming phase in `step-1-brainstorm.md`
2. Follow the prompts in each file sequentially
3. Each step builds upon the previous ones to create a complete product development roadmap
